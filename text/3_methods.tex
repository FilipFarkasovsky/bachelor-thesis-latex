\chapter{Classical Methods}

\section{Kruskal Wallis Filter}

One-way analysis of variance (ANOVA) represents a class of statistical methods used to test whether multiple groups originate from the same distribution.The method is based on decomposing total variability into within-group and between-group components. Formally, the ANOVA test statistic can be expressed as the ratio of within-group to between-group variation.

However, ANOVA relies on the assumption of normally distributed data. In cases where this assumption is violated, a nonparametric alternative is required. For this reason, we employ the Kruskal–Wallis H test, which does not assume normality and is based on rank statistics.

The Kruskal--Wallis test statistic is given by:
\[
H = \frac{12}{n(n+1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i} - 3(n+1),
\]
where \(k\) denotes the number of groups, \(n\) is the total number of observations, \(n_i\) is the number of observations in the \(i\)-th group, and \(R_i\) represents the sum of ranks for the \(i\)-th group.

Each feature is evaluated independently with respect to the target variable, and features with higher test statistic values are considered more relevant. The application of this method to feature filtering in microarray data is documented in Grisci et al. (2019).

Since the test evaluates each feature separately, the method is univariate and does not account for potential dependencies or interactions between features. Kruskal Wallis test yields feature importance scores and is therefore classified as a weight-based feature selection approach.

\section{Mutual Information Filter}
Mutual Information, as introduced in Section XXXXX, is applied as a filter-based feature selection method. It allows measuring the relevance of each feature by quantifying how much information it provides about the target variable. Based on these values, features can be assigned importance weights. Similarly to other univariate filters, each feature is evaluated independently, without accounting for dependencies or interactions between variables.

\section{The Minimum Redundancy Maximum Relevance}
Minimal Redundancy Maximum Relevance (mRMR) XXXXXXXPeng, H., Long, F., Ding, C. (2005)XXXX. is a filter-based feature selection method that iteratively selects features by maximizing relevance to the target variable while minimizing redundancy with respect to the already selected subset. Relevance and redundancy are defined in Sections XXXXX and XXXXX, respectively. At each iteration, the method selects the feature \( x_j \in X \setminus S \) that maximizes:

\[
x_j = \arg\max_{x_j \in X \setminus S} \big[ I(x_j; c) - R(x_j, S) \big]
\]

where \( X \) is the full set of attributes, \( S \) is the set of already selected features, \( I \) is the mutual information function measuring relevance to the class label \( c \), and \( R \) is the redundancy function measuring dependence with respect to the selected subset.

The algorithm is stopped after selecting a fixed number K of features. This procedure results in a weighted ranking of the K-best features.



\begin{algorithm}[H]
\caption{ReliefF Pseudo-code}
\KwIn{$R$: set of all instances, $C$: set of classes, $k$: number of neighbors}
\KwOut{$W$: vector of feature weights}

$n \leftarrow |R|$\;
$W \leftarrow \mathbf{0}$ of size $|A|$\;

\For{$i = 1$ \KwTo $|R|$}{
    $H \leftarrow k\_nearest\_hits(k, R_i, R)$\;

    \ForEach{$c \in C \setminus class(R_i)$}{
        $M_c \leftarrow k\_nearest\_misses(c, k, R_i, R)$\;
    }

    \For{$a = 1$ \KwTo $|A|$}{
        \ForEach{$hit \in H$}{
            $W[a] \leftarrow W[a] - \frac{diff(R_i, hit)}{n \cdot k}$\;
        }

        \ForEach{$c \in C \setminus class(R_i)$}{
            \ForEach{$miss \in M_c$}{
                $d \leftarrow \frac{P(c)}{1 - P(class(R_i))} \cdot \frac{diff(R_i, miss)}{n \cdot k}$\;
                $W[a] \leftarrow W[a] + d$\;
            }
        }
    }
}

\Return $W$\;
\end{algorithm}
